Passerelle

Entre ta clé pour ouvrir tes apps

Les apps vivent dans des dépôts privés. Cette page ne contient aucun secret : elle les lit avec ta clé, qui reste dans ce navigateur.

Créer une clé en lecture seule
  1. Ouvre la page de création d'une clé sur GitHub.
  2. « Repository access » : choisis « Only select repositories » et coche les dépôts privés voulus (ajoute aussi passerelle-privatedata pour lire tes réglages de tuiles).
  3. « Permissions » → « Repository permissions » → « Contents » : Read-only.
  4. Choisis une date d'expiration, génère la clé et copie-la ici.
Utilise une clé distincte de celle de tes apps de déploiement : celle-ci ne doit pas pouvoir écrire.
    Aucune app pour l'instant. Touche « Découvrir » pour repérer les pages HTML de tes dépôts, ou « Gérer » pour en ajouter une à la main.
